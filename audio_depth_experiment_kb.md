Sources: `context_and_response_summary.md` and `kang-changwoo-audio-depth-estimation-8a5edab282632443.txt`. This file preserves experiment history, including failed/negative/ambiguous results. UNKNOWN means not present in uploaded snippets.

## 0. Project Core Summary

Main task: **binaural / echo-based audio → omnidirectional ERP depth map**. Final deployment constraint: **test-time input must be binaural audio only**; RGB, Ambisonics/FOA, GT depth, and oracle geometry are not allowed at inference. Ambisonics/FOA/RGB may be used only as training-time privileged supervision, auxiliary targets, distillation teachers, geometric priors, or intermediate representations.

Main hypothesis under revision: FOA/Ambisonics contains spherical acoustic geometry that may help depth, but current evidence does **not** robustly support “Ambisonics improves binaural-only depth” as a main claim. Compact 4D FOA RMS is weak; temporal pressure-direction covariance / covariance energy maps are the most physically defensible next Ambisonic targets. The strongest paper framing is **Spatial Geometry Distillation for Binaural Echo Depth**, with Ambisonics demoted unless it beats strong binaural/RGB baselines under strict controls.

Strict success criteria: same split/cache/protocol, final test input binaural-only, ≥1% RMSE or AbsRel gain over strong baseline or repeated seeds/paired per-sample evidence, shuffled/wrong-scene/random-rotated Ambisonics controls, and RGB+Ambisonics > RGB-only if Ambisonics is a main claim.

## 5. Important Implementation Details

| Detail | Why it matters |
|---|---|
| Test-time modality contract | Many top rows use FOA/energy input at test; mark ORACLE/NON-DEPLOYABLE for final binaural-only claim. |
| Dataset tuple routing | No ambisonic: 2-tuple; waveform: 3-tuple; FOA: 4-tuple; distance bins: 5-tuple; FOA+waveform+bins: 6-tuple; N2: 7-tuple; RGB: 5-tuple. Model routing in `test.py` and train steps depends on tuple length/model family. |
| FOA rotation before target derivation | Rotation must happen on raw IR, not RMS after the fact. Rotating RMS alone is ill-defined. |
| sample_idx vs dataset idx | `sample_idx % 4` is required because depth filtering drops samples and breaks dataset index cyclicity. |
| Channel convention | ACN `[W,Y,Z,X]`; several comments elsewhere write `[W,X,Y,Z]` conceptually. Preserve this as possible notation conflict; implementation uses `[W,Y,Z,X]`. |
| Covariance vs RMS | Old RMS-per-channel SH projection is physically wrong for energy maps because it ignores cross-channel covariance. |
| gt_energy_window | `early_mid` cuts at sample 13000 (~295 ms), dropping diffuse late tail; used in renew/n4/n9/echodiff SH side configs. |
| Distance-bin edges | Default K=8 uses geometric distance edges 0.2–10 m; non-default K uses equal-time edges over same range. |
| Loss defaults | Most depth models use BerHu + SILog (`w_berhu=1.0`, `w_silog=0.5`; some FOA0415/N2 use `w_silog=1.0`). |
| FOA original loss | `L = depth_weight*depth + foa_weight*(L1+cosine) + hist_weight*SHHistogramAlignmentLoss + optional KL/latent`. |
| N4 sparsity loss | If model emits `gate`, train path adds `lambda_sparsity * sigmoid(gate).mean()`. |
| n9_0425 freeze_n3 | `freeze_n3=true` freezes n3 predictor; `lambda_sh>0` only fine-tunes n3 if `freeze_n3=false`. |
| EchoDiffusion CIDE | Wav2Vec2 branch loaded; uses speech-pretrained features and may be off-distribution for RIR. |
| Pin memory fix | `data/dataloader.py`: validation/test set `pin_memory=False`, `persistent_workers=False`, timeout=120 to avoid validation hangs. |
| Checkpoint loading | `test.py` falls back to `strict=False` and strips `module.` if needed; older failures often from checkpoint naming/loading mismatch, not model design. |
| FOA eval bug | Older high FOA_L1/low FOA_COS results may be invalid; exp396 reruns prove a fix. |
| Root train.py missing | Scripts/docs reference root `train.py`, but uploaded dump lacks root train.py. Reproducibility requires recovering it or documenting train-step logic from server. |
